# T-0016: ユーザーの反応から、エージェントの返答と提案の質をどう上げるか

- 状態: 継続中
- 試行回数: 1
- 関連 ADR: [ADR-0014](../adr/0014-interaction-events-log.md)、[ADR-0011](../adr/0011-three-path-data.md)、[ADR-0006](../adr/0006-session-memorysaver.md)
- 関連: [T-0015](0015-KEY-ambiguous-shopper.md)(曖昧な発話から絞り込めているかを、本番で測る指標がない)、[T-0003](0003-KEY-llm-context.md)、[T-0005](0005-product-count.md)、[T-0006](0006-KEY-agent-tool-routing.md)

## 問いの背景
構成の良し悪しは、固定した発話と商品によるオフライン評価でしか比べていない(T-0003 回7)。本番の利用者が提案した商品を開いたか、言い直したか、会話をやめたかは記録していない。そのため、ある構成が本番で効いているか、どの発話で外しているかが分からない。

T-0003・T-0005・T-0015 は、決まった指標で構成や振る舞いを比べる問い。この問いは、その指標と評価のケースを本番の反応から得る仕組みそのものを扱う。

## 試行
| 回 | 日付 | やったこと | 結果 | 判定 | 分かったこと | 次 | 根拠 |
|---|---|---|---|---|---|---|---|
| 1 | 2026-10-08 | 応答に `turn_id` と `config_version`(設定から作るハッシュ)を足し、往復の結果・商品カードのクリック・会話のリセットを構造化ログに記録した。ログから構成ごとの指標を出す集計スクリプトを足した。発話の本文は記録しない | バックエンドのテスト 50 件が通過(既知の収集エラー 2 件を除く)。ローカルの API に `text/plain` のクロスオリジン POST を送り、204 とログ 1 行を確認した。本番の数値はまだない | 未判定 | 発話を持たないため、「押さずに次の発話」が言い直しか正当な絞り込みかは区別できない | 本番のログを集計し、構成ごとのクリック率・0 件率などの基準値を取る | [ADR-0014](../adr/0014-interaction-events-log.md) |

## いまの結論
反応を往復と構成に結び付けて記録する仕組みは入れた(回1)。本番の数値はまだ測っていない。商品の購入はモールのサイトで起きるため、Shoppie 側で直接取れる反応は、商品カードのクリック・次の発話・会話のリセット・離脱に限られる。
