> 検索に成功したのに例外で落ちる、モールを指定してもツールを呼ばない、検索できたのに返答を作らない、といった問題がありました。
> そこで、確認を挟まずに初回から検索させ、ツールの後は必ず LLM に戻して返答を作り、0 件ならキーワードを変えて再検索する形にしました。
> いまは LLM 1 ノードとツールノードのループで、使えるモールを並列に検索しています。
