## いまの結論
「画面はフル、LLM は直近のツール結果の最小フィールド」の形(ADR-0011)になった。
ただしトークン数・費用の計測が無く、どれだけ効いたかは言えない。会話履歴には `truncate_messages(max_tokens=1000)` があるが、規約の「直近ウィンドウ+要約」の形かは未確認。
次に触るときは、1 往復の入力トークンを計測して `docs/reports/` に残す。
