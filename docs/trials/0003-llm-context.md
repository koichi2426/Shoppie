# T-0003: LLM に渡す文脈を、比較の体験を残したままどう絞るか

- 状態: 継続中(トークン数はまだ測っていない)
- 試行回数: 5(うち破棄 1)
- 関連 ADR: [ADR-0011](../adr/0011-three-path-data.md)、[ADR-0005](../adr/0005-llm-bedrock-claude-haiku.md)

## 問いの背景
モール API の生レスポンスは大きく、そのまま Bedrock に渡すと入力トークンが膨らむ。件数を削ると比較の体験が損なわれる。
