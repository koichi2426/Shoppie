# 試行の記録(Trials)

Shoppie の「問い」ごとに 1 ファイル。何を試し、何がダメで、だから次にどうしたかを回数つきで残す。
うまくいかずに戻した変更・やめた手法も、1 回として数える。

- 書式は [0000-template.md](0000-template.md)。番号は連番
- 測って判断した実験は [実験レポート](../reports/README.md) に書き、問いの回から参照する
- 設計判断そのものは [ADR](../adr/README.md) に書く。ここからは ADR へリンクだけする

2026-10-05 から記録している。それ以前の回は git の履歴から起こした。判定は、その変更がいまの実装に残っているかで付けている。
