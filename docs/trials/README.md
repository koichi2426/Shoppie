# 試行の記録(Trials)

Shoppie の「問い」ごとに 1 ファイル。**何回やって、何がダメで、だから次はこうした**を
回数つきで残す。失敗した試行・戻した変更・やめた手法も必ず書く。

- 書式は [0000-template.md](0000-template.md)。番号は連番で、一度書いたものは消さない
- コードを変えたら、同じ作業(同じ PR)の中でその問いのファイルに 1 行足し、この表の回数を直す
- **既存の問いと内容が被るなら、そのファイルを更新する。** 新しいファイルは、どの問いとも重ならないときだけ作る
- 起点(誰が決めたか)は推測で埋めない。分からなければ「未記録」とし、本人が確認して埋める
- ルール: [`.claude/rules/activity-record.md`](../../.claude/rules/activity-record.md)。書き忘れは Stop hook が差し戻す
- 測って判断した実験は [実験レポート](../reports/README.md) に書き、必ずどれかの問いの回に紐付ける
- 仕組みは [AgentHub の docs/trials/](https://github.com/koichi2426/AgentHub/tree/main/docs/trials) から移した([ADR-0013](../adr/0013-trials-record.md))

## お気に入り(ファイル名に `KEY`)

人に話す筋の中心。**本人がお気に入りに登録した問いを、本数を限らずここに並べる。**
登録した問いはファイル名の番号の後ろに `KEY` を付ける(例 `0001-KEY-…md`)。登録・解除は本人が決める。Claude は提案だけにとどめる。

各ファイルの末尾に「話すとき」(30 秒の下書きと、深掘りされたときの答えの表)がある。お気に入りは下書き済み、ほかは枠だけ。

## 遡及記録について(2026-10-05)

T-0001〜0014 は、記録を始める前の試行を git 履歴(マージを除く約 150 コミット)から起こしたもの。

- **判定**は「いまのコードに残っているか」で付けた。効果を測った記録は無いので、「成功」は「戻していない」という意味でしかない
- **ダメだった理由**は、コミット本文・ADR に書かれているものだけを書いた。書かれていないものは「未記録」。特に、同じ日に入れて外した変更(T-0001 回1〜6、revert 4 件)の理由はほぼ残っていない
- **起点**はすべて「未記録」。2026-06 以降のコミットの多くに `Co-authored-by: Cursor` が付くが、これは実行者で、誰が問いを立てたかの根拠にはならない。本人が確認して埋める
- 問いに起こしていないもの: README の更新、`Initial commit`・`first` などの雛形、依存の更新(8559248)、ログの整備(dc0a408・96f41a5 の一部)、見た目だけの調整(タイポグラフィ・文言・アイコン描画など)、docs・ADR・`.claude/` の整備
