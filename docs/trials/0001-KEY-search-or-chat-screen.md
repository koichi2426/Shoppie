# T-0001: 会話で商品を探す画面は、検索結果型にするか、チャット型にするか

- 状態: 解決(初回は検索型のランディング、1 往復後にチャット型へ移るハイブリッド)
- 試行回数: 12(うち破棄 6)
- 関連 ADR: [ADR-0003](../adr/0003-frontend-nextjs-web-first.md)
- 関連: [T-0002](0002-KEY-conversation-state.md)、[T-0011](0011-shoppie-motion.md)

## 問いの背景
「話すだけで買い物が進む」ので、会話の形を見せたい。一方で、商品カードは一覧で見比べたい。
この 2 つを 1 画面にどう収めるかを決める必要があった。

## いまの結論
初回は検索型のランディング、1 往復後はチャット型。返答はしょっぴーの吹き出しで出し、商品は発言ごとのカードで並べる。
どちらの形が使いやすいかは、まだ数字では比べていない。
