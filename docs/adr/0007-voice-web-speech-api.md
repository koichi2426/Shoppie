# ADR-0007: 音声入力はブラウザの Web Speech API を使い、タップで起動する

- ステータス: 採用
- 日付: 2026-10-02（記録日。判断はそれ以前。[technical-qa.md](../technical-qa.md) から起こした）

## 背景
音声は体験の入り口。精度より、まず話し始める摩擦を減らしたい。

## 決定
- ブラウザの Web Speech API で音声認識する。未対応のブラウザではテキスト入力にする
- 聞き取りはタップで始める。検索中はマイクを止める

## 理由
- 追加費用なしで仮説を検証できる

## 検討した代替案
| 案 | 良い点 | 見送った理由 |
|---|---|---|
| Whisper / Deepgram などのサーバー側 STT | 精度が上がる | 費用とパイプラインが増える。検証段階では不要 |
| 常時聞き取り | タップが要らない | 誤検知と負荷が重かった（当初はこちらで実装し、変更した） |

## 影響・見直し条件
- 認識精度はブラウザ次第。Instagram 内ブラウザなどで個別の対応が要る
