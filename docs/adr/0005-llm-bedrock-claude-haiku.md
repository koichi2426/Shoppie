# ADR-0005: LLM は AWS Bedrock の Claude Haiku 4.5 を使い、生成は短くする

- ステータス: 採用
- 日付: 2026-10-02（記録日。判断はそれ以前。[technical-qa.md](../technical-qa.md) から起こした）

## 背景
会話 UI なので、1 往復のレイテンシと費用が体験を左右する。商品の詳細はカードに出すので、長い文章は要らない。

## 決定
AWS Bedrock の `anthropic.claude-haiku-4-5-20251001-v1:0` を使い、`max_tokens=256` に抑える。
「短い店員口調の案内＋商品カード」に寄せる。

## 理由
- 日本語のツール選択と、短い店員口調が十分にできる
- レイテンシと費用が小さい

## 検討した代替案
| 案 | 良い点 | 見送った理由 |
|---|---|---|
| より大きいモデル | 精度が上がりやすい | 1 往復の体感速度と費用が悪くなる |

## 影響・見直し条件
- 複雑な条件の交渉や長い説明は苦手。そこが必要になったら見直す
- プロバイダは 1 つだけで、フォールバックはない（テンプレート規約 `llm-wrapper-service.md` の「複数プロバイダ」からの例外）
