# ADR-0001: 設計判断を ADR で記録する

- ステータス: 採用
- 日付: 2026-10-02

## 背景
Shoppie は LLM・会話の文脈・3 つのモール API・2 つのデプロイ先と、判断の分かれ目が多い。
これまでの判断は [technical-qa.md](../technical-qa.md) に Q&A でまとめていたが、
「いつ・何から何に変えたか」を追いにくく、新しい判断を足す場所も決まっていなかった。

## 決定
技術判断は `docs/adr/` に 1 件 1 ファイルで記録する。判断を変えたときは、元の判断と変更の経緯を残す。
既存の判断（0002〜0012）は technical-qa.md から起こした。technical-qa.md は対外説明用の Q&A として残す。

## 理由
- コードと同じリポジトリに置くことで、PR で判断とコードを一緒にレビューできる
- 「何を選ばなかったか」を残しておくと、同じ議論を繰り返さずに済む
- Claude などの AI エージェントが、変更の前に判断の理由を読める
