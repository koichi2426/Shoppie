# ADR-0008: Yahoo!ショッピング・楽天市場・Amazon を横断して検索する

- ステータス: 採用
- 日付: 2026-10-02（記録日。判断はそれ以前。[technical-qa.md](../technical-qa.md)・[marketplace-apis.md](../marketplace-apis.md) から起こした）

## 背景
1 つのモールだけでは比較の価値が出にくい。横断検索が会話 UI の強みになる。

## 決定
- 3 モールをそれぞれツールとして用意し、API の差（パラメータ・認証・アフィリエイト条件）はゲートウェイ層で吸収する
- 使えるモールは設定（環境変数）で決める。プロンプトでも「使えるモールだけ使う」と明示する
- Amazon は Associate の資格が足りず Creators API / PA-API が使えないとき、検索リンクにフォールバックする

## 理由
- 検索の幅はプロダクトの価値。API の差はアダプタで閉じ込められる
- プロンプトで明示しないと、LLM が無い API を「失敗した」と嘘をつく

## 影響・見直し条件
- モールの API 仕様変更に 3 つ追従する必要がある
